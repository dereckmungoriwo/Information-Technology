# ☁️ ITMO 444 – Cloud Computing Technologies

## 👨‍💻 About This Repository

Welcome to my ITMO 444 – Cloud Computing Technologies repository.

I am currently pursuing a Bachelor of Information Technology (B.IT) at Illinois Institute of Technology (Illinois Tech).

This repository documents my academic and practical journey into cloud computing, with a primary focus on Amazon Web Services (AWS). It serves as a portfolio of my coursework, technical documentation, AWS labs, research, assignments, and cloud-based projects.

My goal is to develop practical knowledge of cloud infrastructure, distributed systems, cloud architecture, scalability, reliability, and security.
